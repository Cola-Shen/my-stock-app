# 📈 專業級 AI 投資指揮中心 (Pro AI Stock Station)

這是一個基於 Python 與 Streamlit 開發的自動化股票視覺化與分析工具。旨在協助小資族透過數據科學，實現每個月 1,000 元的定期定額投資計畫。

## 🌟 核心功能
- **🔍 技術分析**：整合 K 線圖、MA20 均線、布林通道與 RSI 指標，掌握精確買賣點。
- **📋 歷史數據**：自動抓取 Yahoo Finance 最新成交紀錄，並進行高低價顏色標註。
- **🔮 財富預測**：內建複利計算引擎，可自定義投入金額與年化報酬率，視覺化資產成長曲線。
- **📰 AI 新聞情緒**：透過網頁爬蟲技術即時分析 Google News 標題，判斷市場多空氛圍。

## 🚀 技術堆疊
- **語言**：Python 3.x
- **前端框架**：Streamlit
- **數據來源**：yfinance (Yahoo Finance API)
- **視覺化**：Plotly (互動式圖表)
- **AI 邏輯**：基礎自然語言處理 (NLP) 關鍵字情緒權重法

## 🛠 如何在本地運行
1. 克隆此專案：`git clone https://github.com/您的帳號/my-stock-app.git`
2. 安裝必要套件：`pip install -r requirements.txt`
3. 啟動應用程式：`streamlit run app.py`
